# خطة مالية المدفوعات والتسويات

تاريخ المراجعة: 4 أكتوبر 2026. هذه خطة للمرحلة التالية، وليست إقرارًا بأن أرصدة الشركات أو رسوم عقد المتجر تمت مزامنتها بالفعل.

## الإصلاح الحالي

- التكاليف تعرض أسماء المصروفات، البنود، التواريخ، التكرار، المبلغ وحالة الدفع.
- المصروف لمرة واحدة يُحتسب مباشرة بتاريخ اليوم افتراضيًا؛ يمكن اختيار تاريخ آخر. لا يحتاج موافقة استحقاق أو تسجيل دفع لكي يدخل تكلفة الفترة.
- تسجيل الدفع يحوّل الحالة إلى مدفوع، ولا يُكرر التكلفة. تُفصل المصروفات المحتسبة عن النقد المدفوع.
- إيقاف جدول المصروف أو تغييره لا يُسقط دفعة مسجلة. العمليات الجديدة تحفظ اسم البند وتصنيفه ومبلغه وقت التسجيل.
- الفترة الافتراضية من أول الشهر إلى اليوم في المالية والاستحقاقات والحسابات العامة. اختيار فترة أخرى يظل متاحًا. جدولة التقارير الآلية اليومية والأسبوعية تظل حسب إعداداتها.
- بيانات المراجعة الحالية: المصروف المسجل بقيمة 5,000 ريال كان داخل الحساب أصلًا، لكن تفاصيله لم تظهر في صفحة التكاليف. كذلك كان الحساب بدون تواريخ يجمع مبيعات كل التاريخ مقابل مصروفات الشهر فقط؛ تم توحيد الفترة.

## الحساب والربط

1. **دفتر مستقل لكل شركة وعملة ومتجر:** رقم الطلب الداخلي ورقم عملية الشركة، عمليات التحصيل Capture، الإلغاء، الرد الجزئي/الكامل، الرسوم، ضريبتها، رسم التحويل، الحجز والتعديلات، دفعات التسوية ورقم المرجع البنكي.
2. **القيم الفعلية والمتوقعة:** التقرير الرسمي هو مصدر الفعلي. عند غيابه تُحسب الرسوم من نسخة العقد السارية بتاريخ العملية وتظهر «متوقعة». دون عقد أو تقرير تظهر «غير معروفة»، لا صفرًا مؤكدًا. إصدار تقرير فعلي يستبدل التقدير ولا يضاف إليه.
3. **منع التكرار:** مفتاح فريد للشركة ونوع الحركة ومرجعها؛ استيراد الملف أو وصول إشعار العملية مرتين لا يزيد المبلغ. مطابقة Capture لا نجاح التفويض وحده؛ وفصل عمليات الاختبار عن الفعلية.
4. **رصيد البداية ضروري:** رصيد الشركة في أول الشهر يشمل عمليات الأشهر السابقة غير المحولة. لا نستنتج رصيدها من مبيعات الشهر الحالي وحدها.
5. **معادلة الرصيد:** الرصيد الافتتاحي + التحصيلات المستحقة − المرتجعات − العمولة − ضريبة الرسوم − رسوم التسويات ± التعديلات − التحويلات المنفذة. الحجز يُعرض منفصلًا عن المبلغ المؤهل للتحويل ولا يُعامل كمصروف.
6. **معادلة الربح:** إيراد معترف به − تكلفة البضاعة − الشحن − رسوم الدفع − المصروفات التشغيلية. تحويل الشركة إلى البنك حركة رصيد، وليس مبيعات جديدة. ضريبة الرسوم القابلة للاسترداد تُفصل عن تكلفة التشغيل وفق معالجة المتجر المعتمدة، ولا تُحسم مرتين.
7. **التواريخ:** تقرير المبيعات حسب تاريخ الاعتراف، المصروف حسب تاريخ حدوثه، الدفع حسب تاريخه، التسوية حسب تاريخها. تظهر تبويبات منفصلة حتى لا تكون أرباح أكتوبر مساوية بالخطأ لتحويلات أكتوبر.

## الصفحات المقترحة داخل المالية

- **تكاليف الدفع:** تجميع شهري لكل شركة، ثم تفاصيل الطلبات والعمولات والضريبة ورسوم التحويل ومصدر الرقم؛ إجمالي فعلي، متوقع، وعدد العمليات ناقصة البيانات.
- **أرصدة الشركات:** الرصيد الافتتاحي، المستحق غير المحول، المحجوز، المؤهل للتحويل، التحويل القادم المتوقع، الموعد المتوقع، آخر تحديث. الرصيد المؤهل لا يعني بالضرورة وجود زر سحب؛ بعض الشركات تحول تلقائيًا حسب الدورة.
- **التسويات:** كل دفعة بمرجعها وطلباتها، الإجمالي والخصومات والصافي، متوقع/أصدرته الشركة/وصل البنك/يوجد فرق. تأكيد وصول البنك بمطابقة كشف البنك، وليس بمجرد حالة الدفع الناجحة أو توقع الموعد.
- **المطابقة:** طلبات بلا عملية، عملية بلا طلب، رسوم ناقصة، ردود غير مرتبطة، فرق بين توقعنا وتقرير الشركة أو كشف البنك. فروق قابلة للمراجعة، دون تعديل صامت للأرقام.
- **التصدير والتقارير:** Excel بأوراق مبيعات ومصروفات ورسوم وأرصدة وتسويات وفروق؛ إشعار أو بريد وفق جدول المستخدم الحالي، يذكر الفعلي والمتوقع والبيانات الناقصة.

يمكن عرض الربح التشغيلي. تسمية EBITDA تحتاج تحديد واستبعاد الفوائد والضرائب والإهلاك والاستهلاك ومعالجة محاسبية واضحة؛ لا نسمّي صافي الرصيد البنكي EBITDA.

## التنفيذ على مراحل

1. تثبيت الحساب الأساسي للمصروفات والفترة — الإصلاح الحالي.
2. إضافة إعدادات عقود الرسوم والدورات مع تاريخ سريان؛ لا نفترض نسبًا عامة. إضافة دفتر الحركات ورصيد افتتاحي وتسويات.
3. استيراد ملفات الشركات مع معاينة ومطابقة ومنع تكرار. API تلقائي فقط للبيانات التي يتيحها حساب التاجر وصلاحياته؛ وجود API دفع لا يثبت وجود API أرصدة وتسويات.
4. تشغيل التوقعات من العقد والتقويم والحد الأدنى ووقت القطع؛ الإشارة إلى أن الموعد تقديري ويتغير بالعطلات والتعديلات والمرتجعات.
5. مطابقة كشف البنك والتقارير، ثم التصدير والتنبيهات. اختبارات: دفع جزئي، مرتجع بعد التسوية، تكرار ملف، تعديل معدل عقد، رسوم مجهولة، تخطي حد التسوية، رصيد افتتاحي، نهاية شهر، عطلة بنكية، تسوية تشمل أكثر من شهر.

للبدء بدقة نحتاج عقد الرسوم والدورة الفعلية لكل شركة، عينة تقرير تسوية أو تصدير منها، ورصيد افتتاحي/كشف تسوية مرجعي. لا نحتاج كلمات مرور داخل المحادثة.
